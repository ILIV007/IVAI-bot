# سناریوی دقیق Smoke Test برای انتشار عمومی IVAI Bot

**هدف:** تأیید عملیِ مسیرهای حیاتی IVAI پیش از معرفی عمومی، با یک حساب Telegram غیرادمین و در یک بازهٔ 10 تا 15 دقیقه‌ای.

**نسخهٔ مورد انتظار:** `v3.3.32`  
**زمان اجرا:** ترجیحاً پیش از انتشار پست معرفی و در ساعات کم‌ترافیک.  
**اجراکننده:** مالک بات یا یک تست‌کنندهٔ قابل‌اعتماد که admin پروژه نیست.

> **قانون Go/No-Go:** اگر هر یک از موارد **بحرانی** شکست خورد، معرفی عمومی را متوقف کنید، screenshot و زمان رخداد را ثبت کنید و فقط پس از رفع و تکرار موفق همان آزمون launch را ادامه دهید. خطاهای ظاهری کوچک که رفتار و امنیت را تغییر نمی‌دهند، مانع launch نیستند اما باید ثبت شوند.

| نتیجه | تصمیم |
|---|---|
| تمام موارد بحرانی Pass؛ حداکثر یک ایراد ظاهری غیرمسدودکننده | **GO — انتشار و معرفی عمومی مجاز است.** |
| یک مورد بحرانی Fail | **NO-GO — معرفی را متوقف کنید، رخداد را ثبت کنید، fix و تکرار آزمون انجام دهید.** |
| مشکل محدود به UI غیرامنیتی، بدون شکست عملکرد | GO مشروط؛ issue ثبت شود و در release بعدی اصلاح گردد. |

## واکنش سریع به خطا

1. زمان دقیق، chat type، دستور یا prompt و screenshot را ثبت کنید.
2. فقط یک بار همان اقدام را تکرار کنید؛ از ارسال پشت‌سرهم updateها خودداری کنید.
3. اگر membership شکست خورد، admin بودن bot در channel و channel ID را بررسی کنید.
4. اگر پاسخ AI نیامد، footer/مدل/mode و خطای Worker را ثبت کنید؛ به‌جای تغییر چند provider، ابتدا یک prompt ساده در Fast mode را تکرار کنید.
5. اگر Mini App روی Connecting ماند، app را ببندید، از داخل Telegram دوباره باز کنید و سپس endpoint root Worker را بررسی کنید.
6. پس از هر fix، فقط بخش Fail شده و سپس H-01 تا H-03 را دوباره اجرا کنید.

> این Smoke Test جایگزین test suite خودکار نیست؛ مکمل انسانی آن پیش از launch است.
